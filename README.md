# Пётр Сидоров

**Автоматизация сбора и обработки данных для бизнеса**

Работаю с внешними источниками данных: сайтами, маркетплейсами, интернет-магазинами, открытыми API. Автоматизирую сбор, нормализацию и проверки качества, подготавливаю результат в удобном формате — от регулярных выгрузок до небольших внутренних инструментов.

## Избранные проекты

- **[Мониторинг лотов на площадке купли-продажи сайтов](https://github.com/petr-sidorov/telderi-lot-monitor)** — регулярный мониторинг каталога площадки: около 17 месяцев истории, 72 среза, порядка 2 000 активных лотов в типичном полном срезе, 49 текстовых признаков. Публичный кейс по сбору и обработке данных с открытым кодом.

- **[Tracker 01](https://github.com/petr-sidorov/tracker-01-kanban)** — Kanban-трекер с ролями и правами доступа на Django и PostgreSQL. Проект выполнен по реальному ТЗ в рамках учебного кейса; развёрнут и доступен как рабочее приложение.

- **[playrix-viki-bot](https://github.com/petr-sidorov/playrix-viki-bot)** — технический кейс по доведению существующего бота до стабильной работы: исправление взаимодействия с Wikipedia API, обработка ошибок, логирование и GitHub Actions; проверены 18 endpoint'ов.

## Кейсы по работе с данными

Готовятся к публикации реальные кейсы (без раскрытия клиентских данных):

- Система сбора и подготовки данных с маркетплейсов и интернет-магазинов (multi-source).
- Регулярный мониторинг ассортимента и отзывов в интернет-магазине.
- Сверка и нормализация карточек сети магазинов в Яндекс Картах.

## Что делаю

- Сбор данных с сайтов и внешних источников
- Нормализация, дедупликация, контроль качества (QA)
- Регулярные мониторинги и обновляемые выгрузки
- Excel / CSV / Google Sheets
- Небольшие внутренние инструменты и автоматизация процессов
